# TIDAL RELAY

[![rank](https://make.fun/badge/best-game-01/Hakimweiwei/makefun-tidal-relay-20261117/rank.svg)](https://make.fun/bounty/best-game-01/leaderboard)
[![reward](https://make.fun/badge/best-game-01/Hakimweiwei/makefun-tidal-relay-20261117/reward.svg)](https://make.fun/bounty/best-game-01)

An original arcade rescue operation in a flooded orbital port. Pilot a salvage skiff, link amber capsules into tow chains, and bring them back to Haven. Flip the tide to reverse luminous current lanes and open matching phase gates. Eighteen rescues across three sectors stand between you and a silent port.

Serve `game/` with any static HTTP server, then open it in desktop Chrome. For example, from the repository root:

```sh
python -m http.server 8080 --directory game
```

Open http://localhost:8080. After the local page loads, gameplay needs no network. All geometry and sound are generated by the original source; there are no runtime dependencies, external assets, fonts or libraries.

Controls: WASD / arrows to steer, or hold the left mouse button to navigate toward the pointer. Space / right click switches tide; P / Escape pauses; R restarts; M toggles sound. Enter launches from the tutorial. Losing window focus pauses automatically. Sound begins after interaction; personal best is saved locally when browser storage is available.

Collect up to three capsules at once. Deliver to the green Haven ring for 100 / 300 / 600 points and reactor energy. A loaded skiff moves more slowly and consumes more energy. Phase changes cost 1.5 energy and have a short cooldown. Rose drones cost 19 energy on contact, followed by a brief shield. Empty reactor ends the operation. Clear all three sectors to win, with remaining energy converted to bonus score.

Package with Node.js 22.18 or later, standard library only:

```sh
node main.ts
```

The default destination is `/output`; set `MAKEFUN_OUTPUT_DIR` to choose another directory. The driver copies the static game and four genuine browser screenshots, then writes `dossier.json` using the exact kit helper at `vendor/makefun-game.ts`. No build step or install is needed.

The simulation is seeded and runs at a fixed 60 Hz. `simulation.js` owns movement, collision, current, rescue, scoring and progression; `render.js` draws the port; `input.js`, `audio.js` and `ui.js` handle interaction, synthesized effects and menus; `main.js` connects them. Its exported `snapshot()` returns a detached state copy for inspection, never a mutable game reference.

Built for [make.fun's Make the best game bounty](https://make.fun/bounty/best-game-01). MIT licensed. Publication, transcript bundling and submission are handled separately by the coordinator.
